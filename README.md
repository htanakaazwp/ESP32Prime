# ESP32Prime

Runs custom Linux distributions on ESP32 microcontrollers with optimized code for IoT projects by makers and developers.

The key benefits of using ESP32Prime include:

- Runs custom Linux distributions on
- ESP32 microcontrollers with optimized code
- for IoT projects by makers

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ESP32Prime.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ESP32Prime, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
